# CaiXv-Kun

一个蔡徐坤打篮球的 pygame 小游戏：控制蔡徐坤左右移动接住篮球，每接 10 个球增加一条命。

## 运行

```bash
pip install pygame
python CaiXvkun/Basketball.py
```

## 操作

- `A` / `←` 左移
- `D` / `→` 右移

## 目录结构

```
CaiXvkun/Basketball.py  主程序
CaiXvkun/cxk.png        角色图片
CaiXvkun/ball.png       篮球图片
CaiXvkun/*.mp3          背景音乐
```
